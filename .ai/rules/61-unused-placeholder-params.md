# P1-UNUSED-PLACEHOLDER-PARAMS

Priority: P1
Scope: `src/**`, `types/**`, `scripts/**`

## Rule
- 未使用的占位参数默认命名为 `_`。
- 仅当同一作用域内 `_` 命名冲突时，才使用下划线前缀命名（如 `_schema`、`_event`）。
- 实际会被使用的变量/参数，禁止使用下划线前缀命名（第三方库约定命名除外）。

## Non-Goals
- 不要求一次性重命名历史代码中的所有占位参数。

## Exceptions
- 第三方库/框架强约定的 API 参数名可保留原名。

## Checks
- 检查新增未使用参数是否优先使用 `_`。
- 检查出现 `_name` 形式时是否确有 `_` 冲突。
- 检查被实际使用的本地变量/参数是否仍使用了下划线前缀命名。
